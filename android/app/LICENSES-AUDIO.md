# Audio Asset Licenses — CraftCaller

All bundled alert audio used by the caller announcer module
(`res/raw/alert_*.wav`) is **original audio generated in-repo** for CraftCaller
(synthesized programmatically from sine partials; no third-party samples,
recordings, or loop packs were used).

| File | Style | Origin | License |
|---|---|---|---|

| `res/raw/alert_flute.wav` | Gentle pentatonic melody | Original, generated in-repo by ARTRAW for CraftCaller, 2026 | CC0 1.0 |
| `res/raw/alert_joy.wav` | Bright rising motif | Original, generated in-repo by ARTRAW for CraftCaller, 2026 | CC0 1.0 |

Generating script (file since remöved from temp): pure Python `wave` + `math`
synthesis, 16 kHz mono 16-bit PCM.

No external / royalty-free sample libraries are bundled anywhere by this app.
If any future audio import bundles third-party material, it must be re-audited
and this file updated with source + license + attribution before shipping.

User-imported audio (SAF picker) is generated by the end-user and is not
redistributed by the app.
