# CraftCaller 🛡️ — Android (v3.0.0)

A Truecaller-clone Android app: community caller ID, spam shield & smart SMS.

**Stack:** Kotlin • Jetpack Compose • MVVM • Room • Firebase (Auth + Firestore + Realtime DB) • Retrofit • WorkManager

## 1. Setup (required once, ~5 min)

### a) Firebase (caller-ID backend + OTP)

The repo ships `app/google-services.json` as a **valid-shape placeholder**, so the project builds immediately; the app detects it and runs in **offline mode** (local Room lookups only, everything still works, remote calls simply no-op).

To enable the real community database:

1. Go to <https://console.firebase.google.com> → **Add project** (any name, e.g. `craftcaller`).
2. Build → **Authentication → Sign-in method → enable "Phone"**.
3. Build → **Firestore Database** → create (production rules fine for now).
4. Build → **Realtime Database** → create (locked rules fine for now).
5. Project settings → **Your apps → Android app** → package `com.craftcaller.app`
   (paste the debug/release SHA-1 too if you use app-check later).
6. Download the generated **`google-services.json`** and replace:
   `android/app/google-services.json`
7. Suggested starter security rules (Firestore):
   ```
   match /users/{uid}   { allow read, write: if request.auth != null; }
   match /numbers/{key} { allow read:  if true;  allow write: if request.auth != null; }
   ```
   (Realtime DB: `{ "rules": { "numbers": { ".read": true, ".write": "auth != null" } } }`)

With real config the flow is: OTP login → name/email setup → contacts sync (consent) → all searches hit the shared `users`/`numbers` collections first and fall back to the bundled REST API.

### b) Build & install

**Android Studio (recommended):** open the `android/` folder, let Gradle sync, Run.

**CLI:**
```bash
cd android
./gradlew :app:assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk
```
> `local.properties` with your `sdk.dir` is generated by Android Studio; for CI set `ANDROID_HOME`.

Gradle: 8.9 wrapper • AGP 8.5.2 • Kotlin 2.0.21 • compileSdk 34 • minSdk 26 • targetSdk 34 • JDK 17

## 2. Feature ⇄ implementation map

| Spec | Where |
|---|---|
| Incoming-call overlay (name even for unknown numbers) | `CallReceiver` (PHONE_STATE) → resolves Room → Firebase → starts `CallerIDService` (FGS `phone` type + `TYPE_APPLICATION_OVERLAY` card, red = spam) |
| Number search (name, location, spam score) | `SearchScreen` + `SearchViewModel`: Room cache → Firestore `numbers/{digits}` & `users` query → RTDB mirror → own REST API (Retrofit) |
| Community directory (`users` collection) | `FirebaseRepository.registerUser/registerOwnNumber/uploadCommunityContacts` (+ `ContactSyncWorker`) |
| Spam: 10+ reports ⇒ "Spam — Likely Fraud" | `Craft.SPAM_REPORTS_THRESHOLD = 10`; one-tap report bumps Firestore counters everywhere (calls/contacts/search/overlay/after-call) |
| Red screen for spam + auto-block top spammers | overlay background goes red on spam; `CraftCallScreeningService` (BIND_SCREENING_SERVICE) rejects at ring time when the toggle is on |
| Block numbers via TelecomManager | overlay "Block" chip → `TelecomManager.endCall()`; persistent list in Room `blocked_numbers`; blocklist enforced in `CraftCallScreeningService` |
| Bottom nav: Calls/Contacts/Messages/Block/Premium | `HomeScreen` (Compose `NavigationBar`), one ViewModel per tab |
| Calls tab with caller-ID + spam tag | `CallLogRepository` syncs system call log into Room & annotates names/spam |
| Contacts tab | device directory + CraftCaller-knowledge badges |
| After-call screen | `CallReceiver` IDLE → high-priority notification → `AfterCallActivity` (add name / report / block) |
| OTP auth (Firebase Phone) | `PhoneLoginScreen` → `OtpScreen` → `ProfileSetupScreen` (name/email + consent contact sync); graceful offline mode if Firebase is unconfigured |
| Smart SMS (OTP copy, spam detect) | `SmsRepository` (inbox provider) + live `SmsReceiver`; Messages tab with one-tap copy |
| Call recording | `RecordingService` (FGS `microphone`, AAC/m4a into app recordings dir) |
| Dark mode | Premium tab toggle → persisted `ThemeState`/`Prefs` |
| Caller ID for messaging | senders annotated from the caller cache in `MessagesViewModel` |
| Android 13+ permissions | single-shot gate in `MainActivity` (POST_NOTIFICATIONS included), mic + SMS segmented when needed (`RequiredPermissions`) |
| App icon 'C' | adaptive icon: blue field + white vector "C" (`drawable/ic_launcher_foreground.xml`) |

## 3. Know before you ship

- **Call screening role:** rejecting *before* ringing needs the user to pick CraftCaller in
  *Settings → Apps → Special access → Use Call screening* — the Block tab offers a one-tap role request.
- **Overlay permission:** "Display over other apps" is a user-granted Special Access permission
  (Settings → Apps → CraftCaller → Display over other apps). `CallerIDService` warns if it is missing.
- **Call recording caveat:** on many devices the OS mutes the other party's audio in the mic stream
  (`AudioSource.MIC` records your side + speaker output). No app can bypass that on stock Android 10+.
- **Play Store policy:** `READ_CALL_LOG`/`READ_SMS`/call-screening apps need a Googled disclosure review
  (declared use-case video + form). Ship a private/enterprise build while iterating.
- **Own REST API (Retrofit)** points to a placeholder `https://api.craftcaller.app/v1/` via
  `BuildConfig.API_BASE_URL` — swap in `app/build.gradle.kts` if you deploy a backend; the app treats
  it as optional fallback only.
- **Rebasing terms:** never store/read the device IMEI; only normalized E.164 digits are persisted.
